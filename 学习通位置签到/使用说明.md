# 超星学习通自动签到 — 使用说明

---

## 一、命令速查

| 命令 | 说明 |
|---|---|
| `pnpm build` | **构建**：将 TypeScript 源码编译为 JS，输出到 `build/` 目录。每次修改代码后需重新执行。|
| `pnpm serve` | **启动后端 API 服务**：启动 Web 面板所需的后端接口，必须先运行此命令才能使用网页端。|
| `pnpm preview` | **启动前端网页服务**：启动 Web 面板，提供图形化界面。|

---

## 二、你需要的功能：无人值守自动位置签到

### 使用场景

> 上课前提前配置好经纬度 → 开启监听 → 离开电脑 → 一个半小时后老师发签到 → 程序自动完成位置签到

**完全支持。** 程序通过 WebSocket 与超星 IM 服务器保持持久长连接，实时接收签到消息推送，无需任何手动干预。

---

## 三、首次使用：完整流程

### 第一步：构建

```bash
pnpm build
```

构建成功后 `apps/server/build/` 目录会出现编译后的 JS 文件。**之后只要不修改代码，无需重复构建。**

---

### 第二步：启动服务

**步骤：**

1. **启动后端 API 服务**（必须保持运行）：
   ```bash
   pnpm serve
   ```
   终端显示 `API Server: http://localhost:5000` 表示启动成功。

2. **打开网页面板**：
   `pnpm serve` 运行后，在**另一个新终端窗口**运行：
   ```bash
   pnpm preview
   ```
   然后访问 `http://localhost:4173`（终端会提示地址）。

   > 💡 **为什么不能直接打开 `dist/index.html`？**  
   > React 应用使用 ES 模块，浏览器的 `file://` 协议会因 CORS 限制阻止 JS 加载，导致白屏。必须通过 HTTP 服务访问。

3. **添加账号**：
   - 点击 **"添加用户"**
   - 输入学习通绑定的手机号和密码
   - 确认登录

4. **配置签到参数**：
   - 右键（或长按）用户卡片，选择 **"监听配置"**
   - **签到延时（秒）**：一般填 `0` 或 `10`（避免太快被检测）
   - **模拟客户端 IP**：填写学校校园网 IP，可显著提高签到成功率。获取方法：
     ```
     打开 cmd / 终端，运行：ping 学校域名
     例：ping cdut.edu.cn  →  得到 IP，填入此处
     ```
     若不知道或不确定，可留空（程序会使用默认值）。
   - **预设地址**：填写 **经度、纬度（百度坐标系）** 和 **详细地址**（见第四节获取方法）
   - 可添加多个备用地址，程序会依次尝试
   - 点击确认保存

5. **开启自动监听**：
   - 点击用户卡片上的按钮（显示"未开启自动签到"）
   - 变为 **"自动位置签到中"** 即表示监听已启动 ✅

6. **离开即可**，程序在后台持续监听，检测到签到自动处理。

---

### ⚠️ 关于端口冲突（`EADDRINUSE :::5000`）

`pnpm serve`（后端）和 `pnpm dev`（开发模式）都需要使用 **5000 端口**。如果同时运行两个，会报端口占用错误。

**正确使用方式（两个终端同时运行）：**

```
终端 1：pnpm serve      ← 后端 API 服务（端口 5000）
终端 2：pnpm preview    ← 前端网页服务（端口 4173）
浏览器：访问 http://localhost:4173
```

> ⚠️ **不要** 在已运行 `pnpm serve` 的情况下再运行 `pnpm dev`，会产生端口冲突。  
> `pnpm dev` 仅在修改代码时使用（会自动同时启动前后端）。

## 四、获取百度坐标（经纬度）

> ⚠️ **必须使用百度坐标系（BD-09）**，不能用高德或 GPS 坐标，否则位置会偏移几百米被拒！

**获取步骤：**

1. 访问：https://api.map.baidu.com/lbsapi/getpoint/index.html
2. 在搜索框搜索你的**学校名称或教学楼名**
3. 点击地图上的**精确上课位置**（如你坐的教室所在的楼）
4. 页面右上角会显示 **经度（lon）** 和 **纬度（lat）**

示例：
```
经度：104.156990
纬度：30.684211
详细地址：四川省成都市某某大学第一教学楼
```

## 五、自动位置签到机制详解

```
老师在学习通发起签到
       ↓
超星 IM 服务器推送消息（实时，< 1 秒）
       ↓
本程序收到消息，识别签到类型（位置/普通/手势/签到码）
       ↓
[若是位置签到]
  使用预设地址 1 发起签到（最多重试 3 次）
  若失败 → 使用预设地址 2（最多重试 3 次）
  若失败 → ... 依次尝试所有预设地址
       ↓
签到结果实时打印在终端（彩色日志）
       ↓
（可选）发送邮件通知签到结果
```

**关键参数：**
- 重试次数：**每个地址最多 3 次**
- 重试间隔：**2 秒**
- 心跳日志：**每 10 分钟**打印一次，确认监听仍在运行
- Cookie 验证：**每 30 分钟**验证一次 Cookie 有效性，失效立即报警
- 断线重连：**最多 20 次，每次间隔 5 秒**（网络短暂波动不会停止监听）

## 七、支持的签到类型

| 签到类型 | 是否自动支持 | 说明 |
|---|---|---|
| ✅ 位置签到 | **是** | 自动使用预设百度坐标，含多地址轮询 + 3次重试 |
| ✅ 普通签到 | **是** | 自动完成 |
| ✅ 手势签到 | **是** | 自动完成 |
| ✅ 签到码签到 | **是** | 自动完成 |
| ❌ 拍照签到 | 否 | 已禁用，需手动完成 |
| ❌ 二维码签到 | 否 | 已禁用，需手动完成 |

## 八、常见问题

**Q：位置签到提示"位置不对"？**

坐标系错误。请到 https://api.map.baidu.com/lbsapi/getpoint/index.html 重新获取百度坐标系坐标。

如果坐标正确但仍失败，请检查 **"模拟客户端 IP"** 配置——填写学校校园网 IP 可明显提高成功率（见第三节第4步）。

**Q：如何获取学校校园网 IP？**

打开 cmd 或终端，运行：
```
ping 学校域名
```
例如：`ping cdut.edu.cn` → 获取到的 IP 即为校园网 IP，填入监听配置的"模拟客户端 IP"字段。

**Q：提示"身份验证失败"或 Cookie 失效？**

Cookie 有效期约 **5~7 天**。Cookie 失效后有两种恢复方式：

- **推荐**：右键用户卡片 → 选择 **"刷新凭证（Cookie 失效时用）"** → 程序自动重新登录，**已配置的坐标地址完全保留**，无需重新填写。
- 备用：删除账号后重新添加（需重新配置地址）。

终端每 30 分钟会自动验证 Cookie 有效性，失效时会显示醒目的红色警告。

**Q：开启监听后能关闭浏览器吗？**

可以。`pnpm serve` 是后端服务，监听进程在后台独立运行，与浏览器无关。只要 **不关闭运行 `pnpm serve` 的终端窗口**，监听就不会中断。

**Q：老师发了签到但没有自动签到？**

检查终端日志：
1. 是否有 `❌` 红色错误（位置不对 / 凭证过期 / 未配置预设地址）
2. IM 连接是否断线且未成功重连（超过 20 次重连失败后会停止）
3. 老师发起的是否为不支持类型（拍照/二维码）
4. 心跳日志是否在正常输出（如果超过 10 分钟没有心跳日志，说明程序可能已崩溃）
