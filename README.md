# XuexitongSign

一个用于学习通（超星）的自动化位置签到工具。目前通过 Node.js 与超星 IM 服务器保持持久长连接，实现无人值守的实时自动签到。项目采用 Monorepo 结构，提供独立的 Web 图形化面板进行配置，支持多账号管理与多预设地址轮询。经过测试已经成功

由于目前并未打包成可执行的客户端软件，部署与使用需要具备一定的 Node.js 环境基础。

## 功能特性

*   **支持的签到类型**：位置签到、普通签到、手势签到、签到码签到。
*   **不支持的类型**：拍照签到、二维码签到（需手动处理）。
*   **核心机制**：监听 WebIM 实时消息推送，包含延迟防检测机制。
*   **多地址轮询**：针对位置签到，支持配置多个百度坐标系预设地址，自动按序重试。
*   **网络欺骗防拦截**：支持配置校园网 IP 伪装，以显著提高位置签到的服务端校验成功率。
*   **消息推送**：支持通过 NodeMailer 配置邮件推送最终的签到执行结果。

## 技术栈

*   **架构管理**：pnpm workspace, Turborepo
*   **后端服务 (`apps/server`)**：Node.js, Koa, jsdom, ws (WebSocket)
*   **前端面板 (`apps/web`)**：React, Vite, Material UI
